# SecureStack – IBVAP

### AI-Based Intelligent Video Analytics Platform for Border Surveillance using Existing CCTV Infrastructure

SecureStack is an AI-powered video analytics platform that transforms existing CCTV cameras into an intelligent surveillance system for border security.

## 🚀 Features

- 👤 Person Detection & Tracking
- 🚗 Vehicle Detection
- 🚧 Virtual Fence / Intrusion Detection
- 🔔 Real-Time Alerts
- 📸 Event Snapshots & Logging
- 📹 Multi-Camera Monitoring
- 👨‍💼 Admin & Operator Dashboard

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** FastAPI
- **AI/CV:** YOLO, OpenCV, ByteTrack
- **Database:** PostgreSQL
- **Communication:** WebSocket
- **Video Input:** RTSP / IP CCTV
